0Arbetsordning – Nytt objekt blir ledigt

Exempel: Förråd 2 blir ledigt

1. Uppdatera fastighet.json (forrad-2)
- Sätt objektet som ledigt.
- Kontrollera pris.
- Kontrollera beskrivning (beskrivningar/forrad2.txt).
- Kontrollera bilder (bilder/forrad2-1.jpg, forrad2-2.jpg osv).

2. Testa lokalt
- Kontrollera att objektet visas under Lediga objekt.
- Kontrollera att objekt.html?id=forrad-2 fungerar.
- Kontrollera bilder, pris och text.

3. Uppdatera sitemap.xml
- Öppna sitemap-mall.txt.
- Kopiera objektets <url>...</url>-block.
- Klistra in det i sitemap.xml.
- Uppdatera lastmod till dagens datum.

4. Publicera webbplatsen med GitHub Desktop
- Commit alla ändrade filer samtidigt.
- Push till GitHub.

5. Vänta tills GitHub Pages publicerat webbplatsen.

6. Google Search Console (search.google.com/search-console?resource_id=sc-domain:sodermanfastighet.se)
- Klicka på menyn till vänster: Webbplatskartor (Sitemaps).
- I fältet: Lägg till ny webbplatskarta, skriv: https://sodermanfastighet.se/sitemap.xml
- Klicka "Skicka"

7. Klicka på menyn till vänster: Granskning av webbadress 
- sodermanfastighet.se/objekt.html?id=forrad-1
- Klicka "Testa den aktiva webadressen"
- Klicka på "Begär indexering".
- sodermanfastighet.se/objekt.html?id=forrad-2
- Klicka "Testa den aktiva webadressen"
- Klicka på "Begär indexering".



När objektet blir uthyrt
- Sätt objektet som ej ledigt i fastighet.json.
- Ta bort objektets <url>-block ur sitemap.xml.
- Uppdatera lastmod.
- Commit alla ändrade filer.
- Push.
- Skicka in sitemap.xml igen i Search Console.
