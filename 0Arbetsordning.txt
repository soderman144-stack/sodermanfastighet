SEO-checklista – När ett nytt objekt blir ledigt

Exempel: Förråd 2 blir ledigt

1.  Uppdatera fastighet.json (forrad-2)

-   Sätt objektet som ledigt.
-   Kontrollera 
      pris 
      beskrivning - beskrivningar\forrad2.txt 
      bilder - bilder\forrad2-1.jpg ,forrad2-2.jpg osv

2.  Testa lokalt

-   Kontrollera att objektet visas under Lediga objekt.
-   Kontrollera att objekt.html?id=forrad-2 fungerar.
-   Kontrollera bilder, pris och text.

3.  Publicera webbplatsen med Github Desktop

-   Commit
-   Push till GitHub
-   Vänta tills GitHub Pages publicerat sidan.

4.  Uppdatera sitemap.xml

-   Öppna sitemap-mall.txt.
-   Kopiera objektets …-block.
-   Klistra in det i sitemap.xml.
-   Uppdatera lastmod till dagens datum.

5.  Publicera igen

-   Commit
-   Push

6.  Google Search Console

-   Öppna Sitemaps.
-   Skicka in sitemap.xml igen.

7.  Begär indexering
    https://sodermanfastighet.se/objekt.html?id=forrad-2

Klicka på “Begär indexering”.

8.  Klart

När objektet blir uthyrt: - Sätt objektet som ej ledigt i
fastighet.json. - Commit + Push. - Ta bort objektets block ur
sitemap.xml. - Commit + Push. - Skicka in sitemap.xml igen.
